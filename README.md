# Crop Disease Prediction System

A machine learning-based system for identifying crop diseases from leaf images using image processing and deep learning.

## 📌 Project Overview

This project uses crop leaf images to classify diseases and provide useful information for crop health management.

## 🚀 Key Features

- Crop leaf image preprocessing
- Image augmentation
- Disease classification
- Deep learning-based prediction
- Visual analysis of crop diseases
- Pesticide recommendation based on predicted disease

## 🛠️ Technologies Used

- Python
- TensorFlow
- OpenCV
- NumPy
- Pandas
- Jupyter Notebook
- Machine Learning
- Deep Learning

## 📂 Project Files

- `*.ipynb` — Jupyter Notebook containing the project implementation

## 🎯 Project Objective

The objective of this project is to assist in early identification of crop diseases using computer vision and deep learning techniques.
